# Numerical-methods_Spint_12
Numerical methods_Spint_12- Best prediction model for Rusty used car sales to attract new prospective customers

Introduction
The objective of this project is to develop an optimal model that assists in determining the value of used cars, enabling Rusty Bargain to design an app for estimating market prices. This tool will empower prospective car buyers to assess whether a particular car fits within their budget, facilitating quicker sales conversions, accurate price predictions, and enhanced customer satisfaction. Additionally, it will improve employee job satisfaction by streamlining the pricing process, ultimately contributing to an increase in EBITDA (Earnings Before Interest, Taxes, Depreciation, and Amortization).
Features
- Data preprocessing and feature engineering for accurate predictions
- Implementation of machine learning models to predict car prices
- Handling class imbalance using techniques like SMOTE and class weighting
- Evaluation metrics including AUC-ROC, RMSE, and accuracy scores

Data Preprocessing
- Handling missing values with imputation techniques
- Encoding categorical variables using one-hot encoding
- Scaling numeric columns using StandardScaler and RobustScaler
- Feature selection using correlation analysis with heatmaps

Model Training
- Implementing various models, including XGBoost, LightGBM, and Naïve Bayes
- Hyperparameter tuning with GridSearchCV and RandomizedSearchCV
- Addressing class imbalance using SMOTE
- Evaluating performance through ROC curves and AUC metrics

Evaluation Metrics
Model effectiveness is assessed using:
- RMSE (Root Mean Square Error)
- AUC-ROC for classification performance
- Confusion Matrix & Precision-Recall curves
